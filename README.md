# Sistem Panen

## Deskripsi

Sistem Panen adalah program Python sederhana untuk menghitung total
hasil panen berdasarkan jumlah hasil panen dan harga per kilogram.
Program ini juga memiliki fitur perhitungan diskon.

## Cara Menjalankan Program

1. Pastikan Python sudah terpasang pada komputer.
2. Clone repository ke komputer.
3. Buka terminal pada folder repository.
4. Jalankan perintah berikut:

```bash
python panen.py
